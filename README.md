### 💳 Credit Card Fraud Detection &nbsp;·&nbsp; [![View Repo](https://img.shields.io/badge/GitHub-View_Repo-181717?style=flat-square&logo=github)](https://github.com/tharunshree13/Credit-Card-Fraud-Detection)

> **Problem:** Real-world fraud data is severely imbalanced — models trained naively fail badly.

| 🔧 Approach | 📌 Details |
|:---|:---|
| **Algorithm** | XGBoost Classifier with SMOTE oversampling |
| **Pipeline** | ColumnTransformer + GridSearchCV hyperparameter tuning |
| **Evaluation** | Precision · Recall · F1-Score · AUC-ROC |
| **Key Challenge** | Handling extreme class imbalance without data leakage |

`Python` `XGBoost` `SMOTE` `Scikit-learn` `GridSearchCV` `Imbalanced-learn`
